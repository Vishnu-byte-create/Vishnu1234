ℹ️ About Cr Power

Cr Power is a handwriting notes digitization platform designed for students.

Students can create an account, log in, upload handwritten notes, extract written content using OCR, edit the extracted text and organize it.

Notes are stored locally in the browser. Each registered user has a separate notes collection.

The platform also provides subject detection, topic detection, TXT/JSON export, text-to-speech and an offline chatbot.
